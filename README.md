# Adidas Sales Performance Analysis (Excel)

Analyst: Iyanuoluwa Adeleye 
Tools: Excel Pivot Tables, Formulas, Data Visualization
Dataset: 9,648 transactions (In-Store, Online, Outlet)

### Business Question
Which sales channel performs best for Adidas in terms of revenue, volume, and profitability?

### Analysis Done
- Built 6 pivot tables: Revenue, Units Sold, Count, Average Price, Operating Profit, Margin%
- Compared sales methods to identify pricing strategy

### Key Insights
1. Revenue Leader: In-Store - $356M (39.6%) despite lowest transaction count (1,740)
2. Volume Leader: Online - 939,093 units & 4,889 transactions = small basket strategy
3. Pricing Strategy: In-Store Premium $516.88, Outlet Discount $347.84, Online Value $263.74
4. Profitability: Online most efficient 38.9% margin vs Outlet 35.6%

### Recommendation
Double down on Online for scale, keep In-Store for premium big-ticket sales.
